Student Result Management System

1. Project Overview

The Student Result Management System is a software application designed to manage student information and academic results efficiently.

It helps organize student records, marks, grades and examination results in a structured manner.

2. Project Objectives

- To maintain student information.
- To manage student academic records.
- To simplify result management.
- To calculate and display student grades.
- To reduce manual work and save time.

3. Main Features

- Student Registration
- View Student Details
- Update Student Information
- Delete Student Records
- Marks Management
- Grade Calculation
- Result Management
